# SQL

Практика SQL: SELECT, WHERE, ORDER BY, LIMIT, JOIN (INNER, LEFT, self JOIN), агрегація (COUNT, SUM, GROUP BY).

**[sql_practice.md](./sql_practice.md)** це журнал розв'язаних задач. Кожен запит має:
- **Задача**: умова своїми словами
- **Пастка**: конкретна помилка, яку зробив і виправив
- **SQL**: фінальний робочий запит

Формат навмисно показує не тільки правильні відповіді, а й типові помилки: хардкод значень замість ORDER BY + LIMIT, GROUP BY не за тією колонкою, порожній результат через неточне значення у WHERE, ролі таблиць у self JOIN. Саме таке зазвичай перевіряють на технічній співбесіді для QA.

**Стек:** SQLite (SQLBolt, sql-academy.dev), MySQL (LeetCode).
